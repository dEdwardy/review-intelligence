## 现阶段共识

- 先只做 `Apple App Store`
- 先只服务 `独立 iOS / macOS 开发者`
- 先只解决 `看懂评论 -> 找问题 -> 生成回复 -> 输出行动建议`
- 先不做关键词排名、下载归因、广告 intelligence、多平台支持

## 这套文档怎么用

如果你一会儿新开项目，建议顺序是：

1. 先看 `01-market-validation.md`
2. 再看 `02-product-spec.md`
3. 开发时直接按 `03-mvp-build-plan.md`
4. 新仓库初始化时把 `04-new-project-handoff.md` 一起带过去
